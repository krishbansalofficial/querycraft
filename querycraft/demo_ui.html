    How it works
    
      
    A fine tuned Qwen2.5 Coder model that knows when it is unsure.
    
    
    
    
    
      
    From question to answer
    
      
    
        
    Step 1
    Fit the schema
    
          
    The database schema is read straight from the file and pruned to 1,280 tokens, keeping the tables and
            columns that match the question and hint.
    
        
    Step 2
    Write 8 queries
    
          
    The model writes one greedy query and 8 sampled ones. Each runs against the database with a timeout.
    
        
    Step 3
    Vote, or say unsure
    
          
    Queries are grouped by the rows they return. The largest group wins; its share is the confidence, with
            the threshold chosen on validation data.
    
      
    
    
    
    
    
      
    Read only, on this computer
    
        
    The server listens on localhost only, databases open read only, and uploads stay in a temporary folder
          that is deleted when the demo stops.
